# 演示指南

完整演示约 8 分钟。开始前确认：网页入口正常、模型额度足够、云端费用有人负责、演示结束后有人负责清理。

1. **先看页面**：左侧是历史对话，右侧是当前回答；模型密钥不会进入浏览器。
2. **发送短问题**：后端会从预热池借一台隔离小电脑，这比每次从零创建更快。
3. **解释路线**：浏览器和 Go 后端用 WebSocket；Go 后端和 Codex 用 ACP；网页不需要理解 Codex 内部工作。
4. **解释两种记忆**：PostgreSQL 是人能读的聊天记录，AgenticFS 是 AI 的工作笔记，两者缺一不可。
5. **展示恢复**：刷新页面，重新打开同一个对话，再问一个相关问题；这不是简单把旧文字重新发给模型，而是恢复 ACP session。
6. **展示回收**：本轮结束后，Claim 和已领用的 Sandbox 应被回收，预热池继续补回空闲沙箱。
7. **最后说明风险**：Pulumi 描述网络、集群、存储和入口；NAT、ACK 节点、RDS 和预热池可能持续收费。

演示结束后不要直接执行删除命令。先记录现象和资源，再按部署手册确认数据责任和清理范围。
